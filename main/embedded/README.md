# Built-in fallback cards

Two cards baked straight into the firmware image so the device is testable
with **no microSD card inserted** — handy while the card is sitting in a
reader on your desk.

They are also kept in the normal rotation alongside the SD deck, so they
exercise the in-memory asset path every session rather than only in a failure
case.

Generated by `tools/gen_assets.py`, then copied here. To refresh them:

```bash
cp assets/phonics/cards/a/apple.{png,wav} main/embedded/
cp assets/phonics/cards/c/cat.{png,wav}   main/embedded/
```

Cost is ~267 KB of the 15 MB app partition. The PNGs are already dithered to
the panel's six inks and the WAVs are 22.05 kHz 16-bit mono, exactly as the
SD-card assets are — no special-casing in the firmware beyond reading from
flash instead of a file.
